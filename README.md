2. **Smart Slot Overlap Protection & Free Timing Visibility**:
   - 🟢 **Green Slots**: Open and available for booking.
   - 🔴 **Red Slots**: Occupied / booked (shows customer name tooltip to prevent double-booking).
   - 🟡 **Yellow Slot**: Selected by the customer.
   - Consecutive slots are automatically reserved based on the total service duration to avoid scheduling conflicts.
   - Real-time slot availability counter with a "Show Free Slots Only" toggle.

3. **Custom Haircuts & Pricing Customization**:
   - Add new custom haircuts / services on the fly with custom name, price, duration, and category.

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/uniqabhishek/amit-barber-saloon.git

# Enter the directory
cd amit-barber-saloon

# Start the local server
node server.js
```
Open [http://localhost:5000](http://localhost:5000) in your web browser.
